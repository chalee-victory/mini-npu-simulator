# Mini NPU Simulator

AI가 계산하는 방식(MAC 연산)을 흉내 내는 작은 Python 콘솔 계산기입니다.
숫자 배열로 된 입력 패턴을 십자가(Cross) 필터와 X 필터에 각각 곱하고 더해(MAC) 점수를 구하고,
점수를 비교해 패턴이 어느 모양에 더 가까운지 판정합니다.

> 이 문서는 작업이 진행되면서 계속 업데이트됩니다. (현재: 1단계 핵심 함수 구현 완료)

## 실행 환경

- Python 3.8 이상
- 외부 라이브러리 없이 표준 라이브러리(`json`, `time`)만 사용

## 실행 방법

```bash
python main.py
```

실행 후 모드를 선택합니다.

1. 사용자 입력 (3×3): 필터 A, B와 패턴을 콘솔에 직접 입력
2. data.json 분석: `data.json`의 필터와 패턴을 읽어 일괄 판정

`data.json`은 `main.py`와 같은 폴더에 두어야 합니다.

## 구현 요약

### MAC 연산: `mac(pattern, flt)`

- 입력 패턴과 필터를 같은 위치(`i`행 `j`열)끼리 곱한 뒤 모두 더해 점수를 반환합니다.
- NumPy 같은 외부 라이브러리 없이 이중 `for` 반복문으로 직접 구현했습니다.
- `len(pattern)`으로 크기 N을 구하므로 3×3부터 25×25까지 크기와 상관없이 동작합니다.
- N×N 배열이면 곱셈과 덧셈을 각각 N²번 수행합니다.

### 라벨 정규화: `normalize_label(label)`

데이터에 섞여 있는 여러 표기를 프로그램 내부의 표준 라벨 두 가지(`Cross`, `X`)로 통일합니다.

| 입력 표기 | 표준 라벨 |
|---|---|
| `+`, `cross` (대소문자, 앞뒤 공백 무관) | `Cross` |
| `x` (대소문자, 앞뒤 공백 무관) | `X` |
| 그 밖의 값 | `None` (호출한 쪽에서 라벨 오류로 처리) |

- 먼저 `strip()`으로 앞뒤 공백을 지우고 `lower()`로 소문자로 바꾼 뒤, 대응표(`LABEL_MAP`)에서 찾습니다.
- 대응표에서 `get()`으로 찾기 때문에, 알 수 없는 라벨이 들어와도 오류로 멈추지 않고 `None`을 반환합니다.

### 판정과 동점 처리: `judge(score_a, score_b, label_a, label_b)`

- 컴퓨터는 소수를 2진수로 정확히 저장하지 못해 `0.9`와 `0.8999999999999999`처럼 사실상 같은 값에 미세한 차이가 생깁니다.
- 그래서 `abs(score_a - score_b) < 1e-9`이면 동점(`UNDECIDED`)으로 판정하는 허용오차(epsilon) 정책을 적용했습니다.
- 동점 검사를 가장 먼저 수행합니다. 크기 비교(`>`)를 먼저 하면 미세한 차이만으로 한쪽이 이긴 것으로 판정되기 때문입니다.
- 이긴 쪽 이름을 매개변수(`label_a`, `label_b`)로 받아, 모드 1(`A`/`B`)과 모드 2(`Cross`/`X`)에서 같은 함수를 사용합니다.

### 단위 확인 결과

| 함수 | 입력 | 결과 |
|---|---|---|
| `mac` | 십자가 × 십자가 필터 / 십자가 × X 필터 | 5 / 1 |
| `mac` | 2×2 소수 배열 | 0.9 |
| `normalize_label` | `"+"`, `" X "`, `"Cross"`, `"circle"` | `Cross`, `X`, `Cross`, `None` |
| `judge` | `(5, 1)`, `(1, 5, "Cross", "X")` | `A`, `X` |
| `judge` | `(0.9, 0.8999999999999999)` | `UNDECIDED` |
